# Hungry Hole — Audio Generation Prompts (v4, spec §J25)

Paste each **Prompt** block into your AI music / SFX generator. Save the result with the
exact **File** name into the repo's `audio/` folder (create it). The game picks files up
automatically if present; anything missing just stays silent (spec §J26).

House style for every music track: Pixar-like, instrumental only, warm and kid-friendly,
seamless loop, about 2–3 minutes. If your generator has a separate "negative prompt" or
"exclude styles" field, paste the **Negatives** line there; otherwise append it to the prompt.

Loop tip: if the generator cannot loop natively, ask for an "extended" or "continue" version
and trim at a bar line where the first and last bars share the same chord and texture.

## File checklist

|---|---|
| `audio/menu.mp3` | main menu, chapters, upgrades, settings, mode screens |
| `audio/ch1.mp3` … `audio/ch7.mp3` | looped during that chapter's run (Story, I Spy, Educational) |

| `audio/sfx-ispy-win.mp3` | all five I Spy targets eaten |

The MUSIC toggle in Settings controls the tracks; the SOUND toggle controls all SFX (synth + files).
